# PotatoPack (Minecraft Fabric 26.2)

Pack de mods do servidor do Alan e dos amigos.

## Como instalar
1. Baixe o zip certo em **Releases** (à direita):
   - **Minecraft-Original**: para quem tem o Minecraft comprado.
   - **TLauncher**: para quem usa o TLauncher.
2. Feche o Minecraft.
3. Extraia o zip, leia o "1 - LEIA PRIMEIRO" e dê dois cliques em "2 - INSTALAR".

Os mods pertencem aos seus autores; os créditos estão dentro do zip.
